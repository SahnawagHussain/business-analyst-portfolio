# Sales & Revenue Analysis

## Objective
Analyze sales performance to identify revenue trends and top-performing products, regions, and channels.

## Tools Used
- SQL (Data cleaning & analysis)
- Excel (Pivot tables)
- Tableau (Dashboards)

## Process
1. Cleaned raw data using SQL
2. Calculated revenue and KPIs
3. Analyzed trends using SQL queries
4. Created pivot tables in Excel
5. Built interactive dashboards in Tableau

## Key Insights
- Online sales outperformed offline
- Certain products contributed most revenue
- Revenue peaked during specific months

## Business Recommendations
- Focus marketing on high-performing products
- Invest more in online channels
