## Data Description

This folder contains the cleaned sales data used for analysis and visualization.

### Dataset Overview
The dataset includes order-level sales information such as:
- Order ID
- Customer ID
- Order Date
- Product
- Region
- Sales Channel
- Units Sold
- Unit Price
- Revenue (calculated)

### Data Source
The data was provided as a CSV file and imported into SQL for cleaning and transformation.

### Data Cleaning Steps
- Removed duplicate order records
- Handled missing values in key columns
- Standardized categorical fields (product, region, sales channel)
- Created a revenue column using units sold × unit price

### Usage
This cleaned dataset was used for:
- SQL-based sales and revenue analysis
- Excel pivot table validation
- Tableau dashboard visualization
