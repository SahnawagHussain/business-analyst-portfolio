## Excel Analysis

This folder contains Excel-based analysis performed to validate SQL results and summarize business insights.

### Work Done in Excel
- Imported cleaned sales data from SQL
- Created pivot tables for:
  - Revenue by Product
  - Revenue by Region
  - Revenue by Sales Channel
  - Monthly Revenue Trend
- Used slicers to filter data by region, product, and sales channel
- Created basic charts to support quick business review

### Purpose
Excel was used to cross-check SQL analysis and present quick summaries before building Tableau dashboards.
