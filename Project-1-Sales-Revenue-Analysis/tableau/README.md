## Tableau Dashboard

This folder contains the Tableau dashboard created to visualize sales and revenue performance.

### Dashboard Overview
The dashboard highlights key business metrics and trends, including:
- Total Revenue
- Total Orders
- Average Order Value
- Monthly Revenue Trend
- Revenue breakdown by Product, Region, and Sales Channel

### Features
- Interactive filters for region, product, and sales channel
- KPI cards for quick performance summary
- Clean and business-focused visual layout

### Purpose
The Tableau dashboard was built to present insights from SQL and Excel analysis in an interactive and easy-to-understand format.
