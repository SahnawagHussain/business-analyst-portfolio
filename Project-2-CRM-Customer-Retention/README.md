# CRM Customer Retention Analysis

## Objective
Analyze CRM data to understand customer behavior, engagement, and retention.

## Tools Used
- SQL
- Excel
- Tableau

## Key Analysis
- Customer retention rate
- Repeat purchase behavior
- Customer lifetime value
- Engagement impact on retention

## Business Insights
- Customers with higher engagement showed better retention
- Repeat customers contributed more revenue
- Certain regions showed stronger loyalty

## Recommendations
- Focus on engagement-driven retention strategies
- Target high-value repeat customers
- Improve follow-ups for low-engagement users
