## Excel Analysis

Excel was used to convert SQL analysis into business-friendly summaries and to validate key retention metrics before visualization.
Pivot tables were created to analyze repeat vs one-time customers, compare average order value across customer groups, and summarize customer lifetime value (CLV).
Customer engagement data was also analyzed in Excel to understand its relationship with retention and churn.
Excel enabled quick cross-checking of SQL results, ad-hoc exploration using filters, and easy comparison of customer behavior metrics.
This step ensured data accuracy and made insights accessible to non-technical stakeholders before building Tableau dashboards.
